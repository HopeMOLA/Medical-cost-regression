# Medical Cost Regression Analysis

## Project Overview
This project analyzes medical insurance data to understand the factors that influence healthcare costs. Using **Exploratory Data Analysis (EDA)** and **Linear Regression**, the project identifies key variables that impact insurance charges and builds a predictive model.

The goal is to demonstrate how data analysis and machine learning can be used to uncover insights and predict future medical expenses.

---

## Dataset
The dataset used in this project contains information about individuals and their medical insurance charges.

### Features Included
- **Age** – Age of the individual
- **Sex** – Gender
- **BMI** – Body Mass Index
- **Children** – Number of dependents
- **Smoker** – Whether the person smokes
- **Region** – Residential region
- **Charges** – Medical insurance cost (target variable)

Dataset file:  
`data/insurance.csv`
